# WMS

Um WMS (Warehouse Management System) desenvolvido com Django para controlar entradas, saídas, transferências internas e saldos de produtos por localização dentro de um armazém.

O sistema tem como objetivo facilitar a localização de materiais e permitir o acompanhamento das operações que alteram o estoque, mantendo o histórico de cada movimentação.

## Funcionalidades previstas

- Autenticação e controle de acesso por perfis de usuário.
- Cadastro e gerenciamento de produtos.
- Cadastro e gerenciamento de localizações de armazenagem.
- Recebimento de materiais (inbound).
- Expedição de materiais (outbound).
- Transferência de produtos entre localizações.
- Consulta de saldos por produto e localização.
- Histórico de entradas, saídas e transferências internas.
- Relatórios de estoque e movimentações.
